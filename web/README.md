# CatChess 前端

给 `CatChess-v1.0pro-preview.exe` 用的浏览器界面：能直接和引擎对弈，同时把模型的
内部状态（45 维几何特征、64 个 RBF 专家门控）实时画出来。

## 运行

```bash
# 在项目根目录
node web/server.js
# 打开 http://127.0.0.1:8770
```

改端口：`PORT=9000 node web/server.js`
换引擎：`CATCHESS_EXE=/path/to/other.exe node web/server.js`

直接双击 `index.html` 也能打开，此时是**静态浏览模式**：棋盘、规则、几何视图都在，
但没法走棋（浏览器不能直接起本地进程）。

## 能做什么

- 执红 / 执黑，四档思考时间（0.2 / 0.6 / 1.2 / 2.5 秒）
- 点击棋子走棋，非法着法不会落子；将军、将死、困毙、三次重复都会判定
- 中文记谱（`炮二平五`、`马8进7`），支持同列同兵种的「前/后」写法
- 悔棋（一次退两步）、提示、翻转棋盘
- 右侧遥测：搜索深度、评分、NPS、节点数，以及逐层评分曲线
- 三个小画布画当前局面在 near / line / mid 三张坐标表上的点云、质心与主轴
- 64 专家激活条：哪个专家在主导这一手的评估
- 规则自检：前端 perft(3) 与引擎 perft(3) 对拍，必须都是 79666

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 页面本体（布局、Canvas 棋盘、遥测面板） |
| `server.js` | 本地服务：静态文件 + SSE + UCI 桥（Node 内置模块，无依赖） |
| `xq_rules.js` | 象棋规则内核：走法生成 / 将军判定 / 中文记谱 |
| `geo_browser.js` | 45 维特征与 64 专家 RBF 的浏览器侧实现 |
| `geo_model.js` | 模型权重（由 `export_web_geo.py` 从 `geo45.h` 导出，勿手改） |
| `_check_geo.js` | 开发用：拿 `xq17.exe` 对拍浏览器侧几何复算 |
| `_dev_shot.js` | 开发用：CDP 驱动 headless Edge 截图 / 执行脚本 |

重新导出权重：

```bash
python export_web_geo.py     # geo45.h → web/geo_model.js
```

## 数值口径

- 引擎评分与 `eval` 都是**走子方视角**，页面统一换算成**红方视角**显示，
  所以红优为正、黑优为负，和主流象棋软件一致。
- 右侧「45 维树分」是浏览器复算的纯几何树输出，「引擎融合分」是
  `(65·tree + 35·plane)/100` 之后的结果，两者不等是正常的：
  差值就是平面模型补上的那部分。
- 浏览器复算与 C++ 的一致性：

```bash
node web/_check_geo.js ./xq17.exe 40
# 平均绝对差 0.25cp / 最大 0.45cp，全部落在 lround 取整误差内
```

## 已知限制

1. 引擎是单线程阻塞搜索，思考期间不能悔棋、不能改设置；协议里也没有 `stop`。
2. 没有开局库，每局第一步都靠搜索，同一局面多次开局可能走出不同的棋。
3. `server.js` 只监听 `127.0.0.1`，不要暴露到公网。
4. 长将判负等竞赛规则没有实现，只做了三次重复与 120 回合判和。
